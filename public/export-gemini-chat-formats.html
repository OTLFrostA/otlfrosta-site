STEP BY STEP

How to do it

The same format choices are available for an individual Gemini conversation or a batch of chats.

  1. STEP 01

    Open a conversation or the Workbench

    For one chat, open it in Gemini and use the extension popup. For many chats, open the Workbench and click Sync All.

  2. STEP 02

    Choose Markdown, PDF, HTML or JSON

    Pick the format that matches your goal. Markdown is easiest to edit; PDF and HTML are better for reading; JSON is structured data.

  3. STEP 03

    Select a destination

    Use Browser download, or choose and authorize a folder with Save to local folder for larger batches.

  4. STEP 04

    Export your conversations

    Use Export Current Conversation from the popup, or select conversations and click Export selected in the Workbench.

KNOW WHAT YOU'RE SAVING

Which Gemini chat export format should you choose?

Markdown (.md) is a readable text format that works well in editors, note-taking tools and version control. It is also the format used by optional local Live Save.

PDF (.pdf) produces a portable document using an in-browser Typst/WASM renderer. HTML (.html) works for opening formatted conversations in a browser without returning to Gemini. JSON (.json) is useful for structured archival and other software that can read conversation data.

What to keep in mind

ZIP is packaging, not a fifth format. Browser downloads can bundle several files into a ZIP automatically; local-folder exports write files directly. Images and attachments can be included when enabled and still accessible. Live Save currently targets Markdown only.

Complete user guide ↗
Does Gemini Exporter offer Word or Excel export? +

The published Gemini workflow documented here supports Markdown, PDF, HTML and JSON. We do not advertise Word or Excel as generally available formats.

How does the extension create PDFs? +

PDF documents are compiled locally using a Typst/WebAssembly renderer. Export content does not need to be uploaded to a developer-operated server.

Are generated images and uploaded files saved too? +

When attachment export is enabled, available source images and files may be included. Some uploads or generated resources can expire and cannot be recovered after the source stops serving them.
