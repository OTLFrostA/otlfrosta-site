LOCAL MARKDOWN LIVE SAVE

Automatically back up Gemini chats as Markdown

Want an updated local copy without repeatedly clicking Export? Live Save can update a conversation's Markdown file when Gemini finishes a reply during an active browsing session.

Free and open source. Your conversation exports are processed in Chrome and saved to your own device.

STEP BY STEP

How to do it

Live Save is a local folder workflow, not a remote synchronization service. Start with a manual bulk backup if you want a complete initial snapshot.

  1. STEP 01

    Choose a local folder

    Open the Gemini Exporter Workbench, switch the output destination to Save to local folder and click Choose folder to grant access.

  2. STEP 02

    Select Markdown (.md)

    Choose Markdown (.md) as the output format. Live Save currently does not write PDF, HTML or JSON automatically.

  3. STEP 03

    Enable Live Save

    Turn on Live Save inside the local-folder card. Keep the correct Gemini account and local folder selected.

  4. STEP 04

    Continue using Gemini

    When Gemini finishes new replies during active browsing, the extension updates the corresponding Markdown backup. Check the local files to confirm the result.

KNOW WHAT YOU'RE SAVING

What Live Save does — and what it does not

Live Save is meant to reduce the need to re-export an ongoing Gemini conversation by hand. It writes a Markdown update to the folder you explicitly authorized; the data does not pass through a hosted backup service operated by the extension.

It is not an always-on cloud agent. Updates depend on your browser session, platform access and local folder permissions. Switching away from local-folder delivery or choosing a non-Markdown export format pauses Live Save, even if the preference stays enabled.

What to keep in mind

Important boundaries: Live Save is Markdown-only and works during active browser use. Switching to Browser download or another format pauses it. Browser or folder permissions may need to be renewed after a restart. For a complete snapshot of earlier chats, run a bulk export.

COMMON QUESTIONS

Answers before you export.

Based on the published Gemini Exporter workflow and its current limitations.

Complete user guide ↗
Does Live Save keep working when Chrome is closed? +

No. It is not an independently running cloud service. Keep Chrome open, be signed in to Gemini and maintain the required site and folder permissions.

Can Live Save automatically create PDFs or HTML files? +

Not currently. Live Save targets Markdown (.md) in an authorized local folder. Use a manual export for PDF, HTML or JSON.

Why did Live Save stop after I changed export format? +

Selecting Browser download or a non-Markdown format pauses Live Save. Return to Save to local folder and Markdown; reauthorize the folder if prompted.
